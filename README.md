# engine-core

工作流核心，这里只提供流程定义实现类；另外就是行为和执行器的上层接口，接口的实现由具体的工作流服务提供。

#### 打包发布
```
mvn clean source:jar package deploy -e
```

#### 一期开发支持的模板类型
```
#串行流程
/**
   * +-------+   +------+   +-----+
   * | start |-->| task |-->| end |
   * +-------+   +------+   +-----+
   */
```

```
#并行流程
/**
   *                   +----+
   *              +--->|end1|
   *              |    +----+
   *              |
   * +-----+   +----+
   * |start|-->|fork|
   * +-----+   +----+
   *              |
   *              |    +----+
   *              +--->|end2|
   *                   +----+
   */

/**
   *                      +---------+
   *                      | +----+  |
   *                  +---->| c1 |------+
   *                  |   | +----+  |   v
   * +-------+   +------+ |         | +------+   +-----+
   * | start |-->| fork | |         | | join |-->| end |
   * +-------+   +------+ |         | +------+   +-----+
   *                  |   | +----+  |   ^
   *                  +---->| c2 |------+
   *                      | +----+  |
   *                      +---------+
   */
```

```
#子流程
/**
    *           +------------------------------+
    * +-----+   | +-----------+   +----------+ |   +---+
    * |start|-->| |startInside|-->|endInsdide| |-->|end|
    * +-----+   | +-----------+   +----------+ |   +---+
    *           +------------------------------+
    */
```
